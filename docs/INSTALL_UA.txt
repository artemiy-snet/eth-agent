ETH-AGENT v0.9.4-beta - ВСТАНОВЛЕННЯ НА ТЕЛЕФОН (Termux)
=======================================================

Команди вводити в Termux по одній. Після кожної - Enter.
Рядки, що починаються з # - пояснення, їх НЕ вводити.
Ключі, журнал і налаштування (папка ~/.eth-agent) ці команди НЕ видаляють.


КРОК 1. ЗУПИНИТИ СТАРОГО АГЕНТА І ПРИБРАТИ СТАРІ ФАЙЛИ
------------------------------------------------------
# Робити ДО того, як качати новий архів.

pkill -f agent.cli
cd ~
rm -rf ~/eth-agent-main
rm -f ~/eth-agent-main.zip ~/eth-agent-beta.zip
rm -f ~/storage/downloads/eth-agent-*.zip


КРОК 2. СКАЧАТИ АРХІВ
---------------------
Відкрити чат з Claude на телефоні.
Натиснути на файл eth-agent-beta.zip -> Завантажити.
НЕ відкривати його у файловому менеджері і НЕ натискати "Извлечь".

Перевірити в Termux:

ls -la ~/storage/downloads/ | grep -i eth

# Має бути: eth-agent-beta.zip  розміром приблизно 175 КБ (175000 байт).


КРОК 3. РОЗПАКУВАТИ
-------------------
cd ~
cp ~/storage/downloads/eth-agent-beta.zip ~
unzip -o eth-agent-beta.zip
cd ~/eth-agent-main
cat agent/__init__.py

# Має показати: __version__ = "0.9.4-beta"


КРОК 4. ВСТАНОВИТИ (лише перший раз на цьому телефоні)
------------------------------------------------------
pkg install -y python unzip
bash scripts/termux-install.sh

# В кінці має бути: Готово.


КРОК 5. ЗАПУСК
--------------
bash scripts/run.sh

# Мають з'явитися рядки:
#   ETH-Агент v0.9.4-beta
#   Панель: http://127.0.0.1:8765

Відкрити в Chrome на цьому телефоні:  http://127.0.0.1:8765
У шапці панелі має бути v0.9.4-beta.
Якщо сторінка стара - закрити вкладку і відкрити адресу знову.
Termux не закривати (можна згорнути).


КЛЮЧІ (панель -> Налаштування -> Ключі доступу)
-----------------------------------------------
Після вставки: Зберегти (внизу) -> Перевірити -> Перезапустити агента.

ШІ (Anthropic): ключ з областю "Default" (НЕ "Організація") -> поле "Anthropic API key".
Binance тестовий: ключ з testnet.binance.vision -> поля "(testnet)".
Binance СПРАВЖНІЙ: ТІЛЬКИ в поля "- LIVE". Не в поля testnet.


LIVE (РЕАЛЬНІ ГРОШІ)
--------------------
1. Телефон на домашньому Wi-Fi. Перевірити адресу:

curl -4 -s ifconfig.me; echo

   Ця адреса має бути в ключі Binance (доступ лише з довірених IP).
2. На спотовому гаманці Binance - щонайменше 20 USDT.
3. Панель -> Налаштування:
   - "Binance API key - LIVE" і "secret - LIVE" -> Зберегти -> Перевірити
   - "Live: межа капіталу" = 20
   - "Режим" = live, у полі підтвердження вписати LIVE
   - Зберегти -> Перезапустити агента
4. У шапці - червоний LIVE.


ЩОДЕННО
-------
Запуск:     cd ~/eth-agent-main && bash scripts/run.sh
Зупинка:    CTRL, потім c   (або з іншого вікна:  pkill -f agent.cli)
STOP / STOP FLATTEN / зняти kill switch - кнопки в панелі (Налаштування, внизу).


ОНОВЛЕННЯ (з версії 0.9.2 - одна команда)
-----------------------------------------
1. Скачати новий eth-agent-beta.zip (з чату або GitHub -> Releases).
   Байдуже, як він збережеться - "(1)", "(2)" - скрипт бере найновіший.
2. У Termux:

bash ~/eth-agent-main/scripts/update.sh
cd ~/eth-agent-main && bash scripts/run.sh

   Скрипт сам зупиняє агента, перевіряє архів, ставить нову версію і пише "Оновлено: старa -> нова".
   Ключі, журнал, налаштування не чіпає.


ПОМИЛКИ
-------
"Це не архів"                     -> браузер зберіг сторінку замість файлу: видали його, скачай з чату
"End-of-central-directory signature not found"
    -> файл не архів (браузер зберіг сторінку). Крок 1, потім крок 2 з чату.
"No such file or directory" для zip
    -> ls -la ~/storage/downloads/ | grep -i eth   - перевір назву і розмір
"getcwd: cannot access parent"   -> cd ~
"Порт 8765 зайнятий"              -> pkill -f agent.cli  і знову  bash scripts/run.sh
"code=-2015" (live)               -> змінився IP: curl -4 -s ifconfig.me і оновити IP у ключі
ШІ "HTTP 400 workspace"           -> новий ключ Anthropic з областю "Default"
Помилка pip                        -> python -m pip install pyyaml
