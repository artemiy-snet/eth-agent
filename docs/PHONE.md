# ETH-Агент на телефоні (Android, Termux)

Режими: **paper** — справжні ціни, віртуальні угоди; **testnet** — справжні ордери на тестових грошах Binance.
Режим live (реальні гроші) заблоковано до проходження етапів 1–2 Біблії.

Обмеження телефона: коли телефон без інтернету чи вимкнений, агент стоїть. У testnet на біржі
лишається стоп-ордер, тож позиція захищена й без агента.

## 1. Termux

1. Встанови **Termux з F-Droid** (f-droid.org → «Termux»). Версія з Google Play застаріла.
2. Налаштування Android → Програми → Termux → Батарея → **Без обмежень**.
3. Відкрий Termux і дай доступ до файлів:
   ```
   termux-setup-storage
   ```
   (підтвердь дозвіл у вікні Android)

## 2. Код агента

1. У браузері телефона (з входом у GitHub): `github.com/artemiy-snet/eth-agent/releases` → найновіша версія → **eth-agent-beta.zip**.
   (Або Code → Download ZIP — тоді файл `eth-agent-main.zip`.)
2. У Termux:
   ```
   pkg install -y unzip
   cp ~/storage/downloads/eth-agent-beta.zip ~ && cd ~ && unzip -o eth-agent-beta.zip
   cd ~/eth-agent-main
   bash scripts/termux-install.sh
   ```

Оновлення (з 0.9.2): скачай новий `eth-agent-beta.zip` (з чату або Releases; назва з «(1)» — не страшно), потім
```
bash ~/eth-agent-main/scripts/update.sh
cd ~/eth-agent-main && bash scripts/run.sh
```
Скрипт сам зупиняє агента, перевіряє архів (відкидає «сторінку замість архіву») і ставить нову версію.
Стан, ключі й журнал (`~/.eth-agent`) не губляться. Повна покрокова інструкція — `docs/INSTALL_UA.txt`.

## 3. Запуск і панель

```
cd ~/eth-agent-main
bash scripts/run.sh
```

Без параметрів — портфель (`config.portfolio.yaml`) у режимі з налаштувань панелі (спочатку paper).
Примусово: `bash scripts/run.sh paper` або `bash scripts/run.sh testnet`.

Панель: відкрий у браузері телефона **http://127.0.0.1:8765** (Termux має працювати). Мова UA/EN і тема — кнопки вгорі.
Порада: у Chrome меню ⋮ → «Додати на головний екран» — панель відкриватиметься як застосунок.

| Вкладка | Що там |
|---|---|
| **Огляд** | пульс агента (серцебиття, останній крок, стрічка подій), ціна, капітал, режим ринку, ШІ, наступна подія; графік зі свічками, EMA200, зоною режиму, рівнями входу ботів, позиціями зі стопами й тейками, мітками угод ▲▼, подіями FOMC/CPI і оцінками ШІ ◆; капітал vs ETH; стан кожної стратегії |
| **Прогноз і новини** | повна оцінка ШІ (факти, події, вплив, контроль позицій, аномалії, ідея ШІ-трейдера і вердикт критика), очікування за бектестом, календар, оцінки ШІ на графіку, новини |
| **Угоди** | статистика, результат кожної угоди, таблиця угод, журнал з фільтром |
| **Налаштування** | режим, портфель, ключі (з кнопками «Перевірити»), ШІ, ШІ-трейдер, стратегія, ризик; STOP / STOP FLATTEN / зняти kill switch |

Налаштування зберігаються в `~/.eth-agent/overrides.yaml` і `secrets.env` (не губляться при оновленні коду).
Після «Зберегти» натисни **«Перезапустити агента»** — він перезапуститься сам за кілька секунд.
Live вмикається лише з підтвердженням (розділ 4а). Панель доступна лише з цього телефона.

Зупинити агента повністю: у Termux `Ctrl+C` (двічі, якщо він перезапускається).

## 4. Testnet (тестові гроші, справжні ордери)

1. Відкрий **testnet.binance.vision** → **Log In with GitHub** → **Generate HMAC_SHA256 Key**.
   Скопіюй API Key і Secret Key (Secret показується один раз). На тестовому рахунку вже є тестові USDT і ETH.
2. Панель → **Налаштування** → «Ключі доступу»: встав обидва ключі → **Перевірити** (покаже тестовий баланс)
   → «Режим» = testnet → **Зберегти** → **Перезапустити агента**.
   (Або вручну: `nano ~/.eth-agent/secrets.env` і `bash scripts/run.sh testnet`.)

У цей файл — **лише ключі testnet**. Реальний ключ Binance сюди не вставляти.

## 4а. Live — реальні гроші (рішення Командира)

1. Binance → Управління API: ключ з правом **спотової торгівлі** і **IP-обмеженням**. IP має бути адресою, з якої
   працює телефон: у Termux `curl -s ifconfig.me` → додати цю адресу в ключ. Якщо телефон і комп'ютер в одному Wi-Fi —
   адреса та сама. На мобільному інтернеті адреса змінюється — тоді ключ перестане працювати.
2. Панель → Налаштування → «Binance API key — LIVE» і «secret — LIVE» → «Перевірити» (покаже баланс, IP-обмеження, виведення).
3. «Live: межа капіталу» = 20 → «Режим» = live → у полі підтвердження впиши **LIVE** → «Зберегти» → «Перезапустити агента».
4. У шапці з'явиться червоний блимаючий **LIVE**. У журналі/Telegram — межа капіталу і які рукави не зможуть торгувати.
5. Зупинка — STOP / STOP FLATTEN у панелі або CTRL+c. Стопи лишаються на біржі навіть без агента.

## 5. Telegram (необов'язково)

1. У Telegram напиши **@BotFather** → `/newbot` → придумай ім'я → отримаєш токен.
2. Додай токен у `~/.eth-agent/secrets.env` після `TELEGRAM_TOKEN=`.
3. Напиши своєму новому боту будь-що (наприклад `/start`).
4. У Termux:
   ```
   cd ~/eth-agent-main && python -m agent.cli live --telegram-setup
   ```
   Скопіюй показаний номер у `TELEGRAM_CHAT_ID=`.

Сповіщення приходять про запуск, купівлю, продаж, kill switch і помилки.

## 5а. ШІ-аналітик (необов'язково)

1. Отримай ключ на **console.anthropic.com** → API Keys → Create Key. Вартість ≈ $1–2 на місяць (2–4 запити на добу).
   Там же в Billing → Limits можна поставити місячний ліміт, наприклад $5.
2. Панель → Налаштування → «Anthropic API key» → вставити → **Перевірити** → **Зберегти** → **Перезапустити агента**.
3. Перезапусти агента. На сторінці статусу — блок «Події та новини»: найближча макроподія, оцінка ШІ
   (NORMAL / CAUTION / RISK_OFF), розбір позицій і помічені аномалії. Зміни режиму й аномалії приходять у Telegram.
4. Режим `auto` (у конфігу): ШІ сам, без погодження, може лише пригальмувати нові входи (CAUTION — ½ розміру,
   RISK_OFF — без входів, до 24 год). Ордерів не створює, не продає, стопи не чіпає.
   Лише спостерігати: `mode: shadow` у секції `analyst` конфігу.
5. Рукав **D · ШІ-трейдер** (у `config.portfolio.yaml`, пресет `збалансований+ші`, 10 % капіталу): ШІ сам відкриває
   угоди, але лише за умовами наших стратегій і після перевірки кодом, незалежним ШІ-критиком і ризик-модулем; стоп — на біржі.
   Кожна схвалена угода приходить у Telegram з тезою. Без ключа рукав просто стоїть у USDT.
6. Через 1–3 місяці: `python -m agent.cli ai-review` покаже, чи гальмування справді збігалося з падіннями.

## 6. Аварійні дії

| Що | Як |
|---|---|
| Заборонити нові входи | кнопка **STOP** на сторінці статусу (або `touch ~/.eth-agent/STOP`) |
| Продати все й зупинитись | кнопка **STOP FLATTEN** |
| Зняти STOP і продовжити | `python -m agent.cli live --clear-kill`, потім знову `bash scripts/run.sh …` |
| Почати paper/testnet з нуля | видалити `~/.eth-agent/state_paper.json` або `state_testnet.json` |

## Що очікувати

Денний профіль торгує рідко: ≈ 1–2 угоди на місяць на весь масив. Перші дні — перевірка техніки:
агент бачить ціну, рахує рівні, сторінка оновлюється, testnet-ордери проходять і стоп з'являється на біржі
(видно в розділі Open Orders на testnet.binance.vision).
