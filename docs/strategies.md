## Висновки

1. **A і B — безпечні, але дохід малий.** Перевага стабільна на 7 роках (PF 1,3–1,9, сотні угод), просадка < 10 %.
   Вони заробляють 1–5 % на рік, бо ризикують малою часткою капіталу. B проходить умови етапу 1 Біблії
   (PF > 1,2, ≥ 100 угод, просадка < 15 %), крім «Sharpe не гірший за утримання ETH» на 7 роках (0,56 проти 0,88).
2. **C дає дохід, порівнянний із ринком, але з ринковим ризиком.** Це «утримання ETH з вимикачем»: уникає частини
   ведмежих фаз, однак просадка 60 % на 7 роках. Модель ризику Біблії (0,5 % на угоду, kill switch −10 %) для неї
   не підходить — потрібне окреме рішення Командира і зміна розділу 5.
3. **Головний важіль прибутку — скільки капіталу в ризику**, а не хитрість входу. Більший дохід = більша просадка;
   B1 подвоює дохід B ціною подвоєної просадки.

## Можливі портфелі (для рішення Командира)

| Портфель | Склад | Очікування (за бектестом) |
|---|---|---|
| Обережний | 100 % → B, ризик 0,5 % | ~2–3 % на рік, просадка до ~9 % |
| Збалансований | 70 % → B (ризик 1 %), 30 % → C | ≈ 0,7×5 % + 0,3×(8–32 %) ≈ 6–13 % на рік; просадка ≈ 0,7×9,5 % + 0,3×60 % ≈ до 25 % |
| Агресивний | 50 % → B1, 50 % → C | ≈ 10–18 % на рік; просадка до ~35 % |

Цифри портфелів — оцінка з окремих прогонів, не спільний бектест. Перед вибором — спільний бектест обраної суміші
і walk-forward на 7 роках.
