прибуток реінвестується. 7 років = 2019-01…2026-09, 3 роки = 2023-10…2026-09.
Просто тримати ETH: 7 років +1943 % (просадка 82 %, Sharpe 0,88); 3 роки +61 % (просадка 69 %, Sharpe 0,55).

## Висновки

1. **A і B — безпечні, але дохід малий.** Перевага стабільна на 7 роках (PF 1,3–1,9, сотні угод), просадка < 10 %.
   Вони заробляють 1–5 % на рік, бо ризикують малою часткою капіталу. B проходить умови етапу 1 Біблії
   (PF > 1,2, ≥ 100 угод, просадка < 15 %), крім «Sharpe не гірший за утримання ETH» на 7 роках (0,56 проти 0,88).
2. **C дає дохід, порівнянний із ринком, але з ринковим ризиком.** Це «утримання ETH з вимикачем»: уникає частини
   ведмежих фаз, однак просадка 60 % на 7 роках. Модель ризику Біблії (0,5 % на угоду, kill switch −10 %) для неї
   не підходить — потрібне окреме рішення Командира і зміна розділу 5.
3. **Головний важіль прибутку — скільки капіталу в ризику**, а не хитрість входу. Більший дохід = більша просадка;
   B1 подвоює дохід B ціною подвоєної просадки.

## Портфелі — спільний бектест (реальна спільна просадка)

## Висновок і рішення Командира

1. **Безкоштовного прибутку немає**: що більше дохід, то більша просадка. Найкраще співвідношення дохід/просадка
   (Calmar) на 3 роках — у поточного профілю A; на 7 роках — у C, і воно ≈ як у простого утримання ETH.
2. **Весь великий дохід — від частки капіталу в ETH під час росту ринку (рукав C).** Активні стратегії A/B дають
   стабільну, але малу перевагу (PF 1,3–1,9 на сотнях угод).
3. **Вибір — це вибір допустимої просадки:**

| Готовий пережити просадку | Портфель | Очікувана річна (за бектестом) |
|---|---|---|
| до ~8 % | обережний (B) | 2–3 % |
| до ~20 % (з kill switch 20 %) | B1 + невелика частка C (10–20 %) | 5–10 % |
| до ~50 % | збалансований | 7–22 % |
| до ~65 % | лише режим (C) | 12–39 % |

Минулий результат не гарантує майбутнього; 2019–2021 — винятковий бичачий ринок ETH, він сильно прикрашає C.
